## 简介

《穷人》是陀思妥耶夫斯基的长篇小说处女作，1846 年发表于《彼得堡文集》，一经问世便震动俄国文坛。

全书由小公务员马卡尔·杰武什金与贫苦少女瓦尔瓦拉·多布罗谢洛娃之间的往来书信构成。两人住在彼得堡同一幢破败的出租公寓里，隔着院子与楼梯，靠一封封书信交换日常的琐碎、窘迫、羞怯与温柔。杰武什金收入微薄、衣衫褴褛，却竭力在信里维持体面；瓦尔瓦拉命运多舛、寄人篱下，在病与贫之间挣扎。他们在信里为彼此虚构出一点尊严，也一次次被现实击穿。

小说以书信体的私语，写出了"小人物"的内心世界——贫穷如何磨损一个人，又如何让人在磨损中仍固执地保留善意。别林斯基读后称其为"俄国社会小说的第一次尝试"，而陀思妥耶夫斯基也自此确立了贯穿其一生创作的母题：被侮辱与被损害者的灵魂。
